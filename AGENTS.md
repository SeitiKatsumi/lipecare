# Regras do projeto LipeCare

## Textos em português

- Todo texto visível ao usuário deve usar português do Brasil com acentuação correta.
- Arquivos de interface devem permanecer em UTF-8.
- Não remover acentos para manter textos em ASCII.
- Antes de concluir alterações de interface, executar `npm run lint`.
- O verificador `scripts/check-portuguese-accents.mjs` deve continuar integrado ao lint e ser ampliado quando surgir um novo caso recorrente.
